# Fitkart Web Client

Modern React + TypeScript storefront for **Fitkart**, featuring curated apparel browsing, AI virtual try-on, personalized body-measurement sizing, user profile management, and real-time order tracking.

## Tech Stack

- Vite
- React & TypeScript
- Tailwind CSS & shadcn/ui
- TanStack Query & Axios

## Development

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
```
